#SQL Practice & Interview Preparation

Welcome to my SQL practice repository!

This repository contains my solutions to SQL problems from platforms such as DataLemur and LeetCode.

The main goal of this project is to strengthen my SQL skills, improve analytical thinking, and prepare for technical interviews for Data Analyst and Data Scientist positions.

📚 Topics Covered
	•	Basic SQL Queries (SELECT, WHERE, ORDER BY)
	•	Aggregate Functions (COUNT, SUM, AVG, MIN, MAX)
	•	GROUP BY & HAVING
	•	JOINs (INNER, LEFT, RIGHT, FULL OUTER)
	•	Subqueries
	•	Common Table Expressions (CTEs)
	•	Window Functions (ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD)
	•	Date and Time Functions
	•	Advanced SQL Queries
